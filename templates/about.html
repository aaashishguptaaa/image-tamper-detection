About This Project

Image Forgery Detection and Localization using ELA, SIFT and CNN

Project Goal

Digital image forgery is a growing threat in media, journalism, and legal contexts. This system provides a forensic tool to automatically detect and localize tampered regions in digital photographs using a hybrid approach combining three powerful image processing techniques.

ELA — Error Level Analysis

JPEG images lose quality with each save. When an image is tampered, the edited regions are re-saved at a different compression level than the rest. ELA reveals this inconsistency by re-saving at a known quality and amplifying the pixel difference. Tampered regions appear brighter in the ELA map.

ELA = |Original − Re-saved| × scale_factor

SIFT — Scale Invariant Feature Transform

Copy-move forgery involves copying a region from within the same image and pasting it elsewhere to hide or duplicate content. SIFT detects this by extracting distinctive feature descriptors from keypoints and finding spatially separated matches within the same image using FLANN-based matching with Lowe's ratio test.

CNN — Convolutional Neural Network

A deep CNN trained on ELA representations of real and forged images learns to classify authenticity. The architecture uses 4 convolutional blocks with batch normalization, followed by dense layers with dropout for regularization.

Input: ELA(128×128×3) → Conv×4 → Dense → Sigmoid → P(fake)

Combined Score

Final forgery probability is a weighted combination of all three techniques, giving highest weight to the CNN (most accurate when trained), followed by ELA.

Score = 0.50×CNN + 0.30×ELA + 0.20×SIFT
