⚙️ How It Works

1

ELA Analysis

Re-saves the image at known quality and detects regions with inconsistent compression — a key sign of editing.

2

SIFT Detection

Finds copy-paste forgery by matching feature keypoints within the same image using Scale-Invariant Feature Transform.

3

CNN Classification

A deep convolutional neural network trained on ELA images makes the final REAL/FAKE classification decision.

4

Forgery Localization

The system highlights exactly WHERE the tampered region is using a color heatmap overlay on the original image.
